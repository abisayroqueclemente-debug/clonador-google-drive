Clonador de Google Drive

Copia archivos y carpetas a tu Drive sin descargarlos.

Configuración Requerida

Para usar esta herramienta, necesitas tus propias credenciales de la API de Google. Insértalas en las primeras líneas del código JavaScript de este archivo HTML.

  1. Crea un proyecto en Google Cloud.
  2. Activa la API de Google Drive para tu proyecto.
  3. Crea un "ID de cliente de OAuth 2.0" de tipo "Aplicación web".
  4. En "URI de redireccionamiento autorizados", agrega la URL donde alojarás esta página. Para pruebas locales, puedes usar `http://localhost` y `http://localhost:8000`.
  5. Copia el "ID de cliente" y la "Clave de API" en las variables `CLIENT_ID` y `API_KEY` del script.
